# shipment-form

MIRIAM House of Design — supplier shipment declaration form.

One page, one Make webhook, four personal links:

| Supplier | Link | Language |
|---|---|---|
| Kasba (מתפרה) | `?s=kasba` | Hebrew |
| NYI Fabrics | `?s=nyi` | English |
| OBA Blinds | `?s=oba` | English |
| Coulisse | `?s=coulisse` | English |

Opening the page without a valid `?s=` key shows a "use your personal link" notice.

Files: `index.html` · `a1.js` (config + i18n) · `a2.js` (app logic) · `s1.css` `s2.css`
